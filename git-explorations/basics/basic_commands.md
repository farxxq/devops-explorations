## Basic Commands

1. Initialize git repo
### git init

2. Add remote repo (HTTPS):
### git remote add origin <url>
> **NOTE**: origin is the default remote repo name, you can use any name

3. Add files
### git add .

or

### git add <filename>

3. Commit files
### git commit -m <commit-msg>

4. Push code to remote repo
### git push origin <repo-name>
