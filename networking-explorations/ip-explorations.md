# Ip (`Internet Protocol`) address explorations

Ip address is a way to uniquely identify a device that i connected to the internet.

---

## Two Types:
> IPV4
> IPV6

---

## IPV4

IPv4 (Internet Protocol version 4) is the foundation of the modern internet

> 32 Bit is used to create a unique address (192.168.16.210)
> It is set in a range between the 0 - 255
